# osTicket Helpdesk Lab

## Project Overview

This project demonstrates the installation, configuration, and administration of an osTicket-based IT service desk environment.

The goal of this lab was to simulate a real-world IT support environment by creating a functional helpdesk system capable of managing incidents, service requests, SLAs, escalations, and customer communication.

---

## Technologies Used

- Ubuntu Server
- Apache Web Server
- MariaDB Database
- PHP
- osTicket v1.18.4
- Gmail SMTP

---

## Project Objectives

The objectives of this project were:

- Deploy a working ticket management system
- Configure users, departments, and support workflows
- Implement SLA management
- Simulate real IT support scenarios
- Demonstrate ticket assignment and escalation
- Configure email notifications
