# osTicket Ticket Scenarios

This document outlines the simulated IT support scenarios completed within the osTicket helpdesk environment.

Each scenario demonstrates different IT service management workflows including incidents, service requests, SLA handling, assignment, escalation, and resolution.

---

# Scenario 1 — Wi-Fi Connectivity Issue

## Ticket Type

Incident

## Category

Network Support

## User Issue

User reported being unable to connect to the office Wi-Fi network.

## Workflow Completed

- Ticket submitted through customer portal
- Assigned to appropriate support team
- Troubleshooting performed
- Customer updated
- Ticket resolved and closed

## Skills Demonstrated

- Incident management
- Network troubleshooting
- Customer communication
- Ticket lifecycle management

# Scenario 5 — VPN Connection Failure

## Ticket Type

Network Incident

## Category

Network Support

## User Issue

Remote user unable to connect to company VPN.

## Priority

High Priority

## SLA

High Priority SLA applied.

## Escalation Workflow

Level 1:

Service Desk investigated the issue and confirmed the problem was not caused by the user's local internet connection.

Level 2:

Ticket escalated to Network Support for further investigation.

## Resolution

Network Support corrected the VPN configuration and restored user access.

## Skills Demonstrated

- Incident escalation
- Multi-level support workflow
- Network troubleshooting
- SLA handling
- Resolution management
